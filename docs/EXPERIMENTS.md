# Scope and preserved experiments

This edition packages the existing baseline and matched uniform-versus-central slice experiment. It is a curated source copy, not a replacement for the complete local research workspace. No original files or results were deleted.

The source workspace also contains V2 pooling comparisons, V3 report supervision/fine-tuning, V4 DINO experiments, V5 weak supervision, V6 evidence verification, ACL-specific V7, V8/V9 experiments, availability/supervision audits, and later ensemble investigations. They remain at the original local project path and are not dependencies of the baseline commands in this repository.

Later work includes borrowed pretrained ensembles and checkpoint readers with unresolved rights and competition-eligibility questions. Publishing those assets or their embedded upstream code would need a separate attribution/rights review. They are excluded here rather than assigned an invented license. No weights are included.

A local historical handoff reports a 0.891 reproduced public ensemble and a subsequent 0.892 nineteen-member variant. These are user-reported claims about different third-party ensemble workflows. This edition has no independently verifiable scored Kaggle output/receipt for them. They are not baseline performance results or evidence of original model training. Published upstream scores such as 0.929 or 0.958 are not this project's scores.

The tiny synthetic encoder and the ResNet18 baseline are explicitly distinguished in the README. Engineering smoke results must never be reported as competition or medical performance.
